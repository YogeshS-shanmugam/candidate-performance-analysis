# Candidate Performance Analysis & Recommendation Tool

A Python and Streamlit-based web application that analyzes candidate performance and provides useful recommendations.

## 🌐 Live Demo

[Click here to open the Candidate Performance Analysis App](https://candidate-performance-analysis.streamlit.app/)

## Project Overview

This project analyzes the performance of 100 candidates across different courses.

The system can identify strengths and weaknesses, recommend courses for improvement, track performance across multiple attempts, and pair poor performers with high-performing mentors.

## Features

- Upload CSV or Excel datasets
- View class performance dashboard
- Calculate average student performance
- Identify high, medium, and poor performers
- Identify student strengths
- Identify student weaknesses
- Recommend courses for improvement
- Track improvement between multiple attempts
- Pair poor performers with high-performing mentors
- Download performance reports

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- Google Colab

## Project Files

- `Candidate_Performance_Analysis.ipynb` - Data analysis notebook
- `candidate_performance_app.py` - Streamlit web application
- `candidate_performance_analysis.csv` - Performance analysis dataset
- `requirements.txt` - Required Python libraries

## How to Run the Project

1. Install the required libraries:

    pip install -r requirements.txt

2. Run the Streamlit application:

    streamlit run candidate_performance_app.py

3. Upload a CSV or Excel dataset.

4. View the performance analysis and recommendations.

## Main Outputs

The application provides:

- Class performance statistics
- Performance distribution
- Course-wise average marks
- Individual student analysis
- Strength and weakness identification
- Course recommendations
- Performance improvement tracking
- Mentor pairing
- Downloadable reports
